# HowdyHackGame

A python learning game tailored towards Texas A&M students. Featuring Ms.Rev as your personal tutor. 
This games focus is to give the user a similar feeling to playing childhood pixel games such as Pokémon on the DS. This art style was chosen with the intent to draw attention to keep the users engaged. 
The time limit due to the nature of hackathons was challenging; as freshmen students we didn't have a lot of experience with creating new projects. However after this attempt we learned a great deal that will assist in future projects.
